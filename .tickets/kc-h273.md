# Make time-dependent functions testable

is_restaurant_open_now, format_restaurants_with_menus, and print_menus all call Local::now() internally. This prevents deterministic testing — callers cannot control what now means. Pass a NaiveDate or DateTime<Local> into these functions instead of letting them compute it. Each caller already knows the target date (from day_offset); compute it once and thread it through.

## Acceptance Criteria

- No function below main/handle_arg calls Local::now() directly
- Local::now() is called once in commands.rs and passed down
- All existing tests still pass
- is_restaurant_open_now accepts a NaiveTime parameter instead of reading the clock
